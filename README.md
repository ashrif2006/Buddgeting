BudgetWise - Personal Finance Tracker
BudgetWise is a comprehensive, client-side web application designed to help users manage their finances by tracking income, expenses, budgets, and savings goals. The application features a modern, responsive interface built with Bootstrap and handles data persistence using browser local storage.

Features:
User Authentication: Secure sign-up and login system with multi-user support.

Dashboard: A high-level overview of total balance, recent transactions, and financial health.

Transaction Management: Add and categorize income, expenses, and savings.

Budgeting: Create monthly budgets for different categories and track spending progress with visual progress bars.

Savings Goals: Set specific financial goals, track progress, and set deadlines.

Visual Reports: Insightful charts and graphs (using Chart.js) to visualize spending habits and compare income vs. expenses.

Local Storage: All data is saved locally in your browser, ensuring privacy and quick access without a backend server.

Technologies Used:
Frontend: HTML5, CSS3, JavaScript (ES6+)

Styling: Bootstrap 5.3.0, FontAwesome 6.0

Charts: Chart.js

Data Persistence: Browser LocalStorage

Project Structure:
login.html / signup.html: Authentication entry points.

home.html: Main dashboard with financial summaries.

transactions.html & add-transaction.html: Tools for viewing and recording cash flow.

budgets.html & create-budget.html: Budget tracking and setup.

goals.html & create-goal.html: Savings milestones and goal tracking.

reports.html: Data visualization and financial insights.

Getting Started:
Clone or Download: Save all project files to your local machine.

Open in Browser: Simply double-click login.html or open it using a local live server (like VS Code Live Server).

Create an Account: Sign up with a name and email to start your financial journey.

Usage:
Adding Data: Start by adding your income and then log your daily expenses.

Setting Limits: Go to the "Budgets" section to set limits for categories like Food, Entertainment, or Utilities.

Tracking Goals: Create a goal for a "New Car" or "Emergency Fund" and watch the progress bar grow as you add savings transactions.

Analyzing: Check the "Reports" tab regularly to see where your money is going.
